Offline, always

The app has no network access at all. Timers and settings stay on your Mac.

Voice stays local

Speech is recognised on-device, only while you're talking, and never stored.

Free and open source

Every line is on GitHub. You build it on your own Mac, so you run exactly that code.

Install in one line.

It builds Drift on your Mac, moves it to Applications and opens it. About two minutes.

$ curl -fsSL https://raw.githubusercontent.com/nweinberg97/Drift/main/scripts/install.sh | bash
  1. Open Terminal. Press ⌘ Space and type Terminal.
  2. Paste the line and press Return. If macOS offers the free Command Line Tools, install them and run it again.
  3. Drift appears in the top-left corner. Press ⌥ Space and type 25.
