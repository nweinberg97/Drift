Three keys, from anywhere.

They work in every app, including full-screen ones. Change them in Settings if you like.

⌥Space

New timer

Type a duration, press Return. Return on its own starts your default.

⌥V

Say it

“Start a ten minute timer called break.” Drift stops listening when you do.

⌥T

Hide or show

Hidden timers keep running, and the time moves into the menu bar.

Nothing to sign up for.

Drift is a timer, not a productivity platform.

AccountsStreaksDashboardsSubscriptionsAnalyticsNagging

Offline, always

The app has no network access at all. Timers and settings stay on your Mac.

Voice stays local

Speech is recognised on-device, only while you're talking, and never stored.

Free and open source

Every line is on GitHub. You build it yourself, so you run exactly that code.

Install in one line.

Paste this into Terminal. It builds Drift on your Mac, moves it to Applications and opens it.

$ curl -fsSL https://raw.githubusercontent.com/nweinberg97/Drift/main/scripts/install.sh | bash
  1. Open Terminal (⌘ Space, then type Terminal).
  2. Paste the line and press Return. If macOS offers to install the free Command Line Tools, accept, then run it again.
  3. Drift opens in the top-left corner. Press ⌥ Space and type 25.
