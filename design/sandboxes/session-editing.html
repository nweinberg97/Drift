Breaks between blocks, and editing a running session

Two previews before I build them into Temro. Everything is clickable.

7 · Breaks between blocks

Put a break exactly where you want it

The bug: + Add a break always put the break at the end of the session, after your last block, so there was no way to get one in between.

  • ⋯ on any block adds a break or a block right after it, moves it up or down, or deletes it.
  • + Add a break › Between every block drops a break of one kind between each pair of work blocks in one go (it skips gaps that already have one).
  • The bar at the top shows breaks in their colour, so you can see where they landed.
Try it: open ⋯ on "Writing" and add a Move break, then use Add a break › Between every block › Hydrate.
8 · Edit while it runs

Change the plan without stopping the timer

Expand the widget during a session and click Edit. The timer keeps running while you change things.

  • Current block: give it more or less time with − / +, or rename it.
  • Coming up: rename, change lengths, reorder, delete, or add blocks and breaks anywhere with ⋯.
  • Finished blocks are locked. End times update as you go.
  • Click Done to close the editor. Changes save as you make them, so there's nothing to lose.
